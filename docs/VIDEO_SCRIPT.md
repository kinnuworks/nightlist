# Demo video script (about 3 minutes 20 seconds)

Follows the order in the hackathon's Demo Video Guide: problem, solution, agents, live run, sponsor technology, output.

Record at 1080p, 16:9, browser zoom 110 to 125%, terminal font 18px or larger. Start the app first with `npm run demo` and `npm start`. Close `.env`, clear terminal history and hide every token before recording. Save as `OAH2026-Nightlist-FragmentedIntelligence-Demo.mp4`.

| Time | Screen | Narration |
|---|---|---|
| 0:00 to 0:20 | Worklist home, Gloria Haynes card at the top | "Our entry is for Solving Fragmented Intelligence. A research coordinator at a community cancer clinic has to check every lung cancer patient against every open trial nearby. One check by hand takes most of an hour, so most patients never get one. Community clinics enroll about four percent of adults in treatment trials." |
| 0:20 to 0:45 | Worklist: the four numbers, then "What changed overnight" | "Nightlist does that screen every night. The model reads the public trial text and compiles each criterion into a check. Zetaris runs the checks as SQL over the clinic's records, which the model never sees. Overnight, two trials opened, a genetic test came back, and Nightlist found 205 new matches. It never says eligible: each pair is ruled out with evidence, has no blockers, or names what a person still has to read." |
| 0:45 to 1:25 | Architecture diagram from the README, then the Run page trace | "Eight agents work the night. The Watcher diffs the trial registry. The Guard runs Meterless Scout Intent on trial text. The Compiler writes checks, and the Checker restates each one in plain words and sends any disagreement to a person. The Screener runs the checks through Zetaris. Then the Verifier re-reads the source rows behind every open match and can send one back. Here it did: the Verifier challenged the Screener on this patient because a tissue panel found KRAS and a plasma panel did not. That match now goes to a human read instead of the worklist." |
| 1:25 to 2:15 | Terminal: `curl -X POST localhost:8787/run -d @input_examples/example_1.json`, then click Gloria Haynes, then her new top trial, then expand the EGFR row | "Here's a real run. One POST to /run re-screens the whole clinic in a few seconds and returns Gloria Haynes's matches. Yesterday she had no molecular testing. Last night her plasma NGS came back: EGFR L858R. An EGFR-mutant trial is now at the top of her list, marked new. Every verdict opens to its evidence. This criterion was compiled into a check, here is the SQL the data layer ran, and here is the source row: a report in the lab system, filed under its own MRN format." |
| 2:15 to 2:45 | Run page: Systems panel, data-quality rules, semantic layer tables; then the Compiler and Checker lines in the trace | "Zetaris is the data layer: six sources with no shared identifiers, joined by one semantic layer of ten tables, with six data-quality rules that run every night. Tonight they set aside fifteen lab rows: six under a mistyped record number and nine with no unit. Every model call goes through Meterless Nightshift to NVIDIA Nemotron, and the trace names the model that served each request. World Model is the log behind 'what changed overnight', and H-MEM remembers the coordinator's decisions." |
| 2:45 to 3:20 | Patient Earline Pruitt: memory panel and set-aside list; then docs/EVALUATION.md, the final-test row | "Yesterday the coordinator noted that Earline Pruitt won't travel more than 100 miles. H-MEM kept that, so tonight 27 distant trials were set aside, with the note and who wrote it. We measured the compiler on real criteria it had never seen, labeled blind: 84 percent of compiled checks give the right answer for all 240 patients. The coordinator starts the morning with a list they can act on, not a stack of trials to read." |
